Coding agents, with a fixed finish line

Give the work a real check.

goaly runs a coding agent in a loop. It freezes the success checks first, tests every attempt, and asks for Sign-off only after the checks pass.

Why use goaly

A loop you can inspect.

Set a goal once. Keep the bar fixed. See why an attempt passed, failed, or stopped.

Checks stay frozen

The contract has a recorded hash. Changes to authored checks are detected.

Feedback drives each retry

The verifier reports failures to the agent. Veto-only Sign-off follows a passing check.

Runs stay inspectable

A write-ahead log records the run. You can inspect it and resume after an interruption.

Quick start

One goal. One command.

Requires Node 20 or newer and an installed agent CLI. The default uses the first installed agent: Claude Code, Codex, Droid, then pi.

$ npm i -g goaly
$ goaly "add a /health endpoint returning 200"

The default run is hands-off, capped at 500,000 tokens and 7,200,000 ms, with no Goaly OS sandbox. Use --mode review to approve the frozen contract at Seal.

What DONE means: the frozen verifier ladder passed, and veto-only Sign-off did not veto. DONE records that check outcome. It does not prove semantic correctness; that depends on check quality and model independence.
